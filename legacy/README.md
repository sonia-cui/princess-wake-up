# legacy / v0 原型（2026 年 4 月）

这是「公主，请起床！」最早的可运行原型，原样保留，用来记录项目的真实起点。

- 技术：纯 HTML + CSS + JavaScript，三个文件，直接用浏览器打开 `index.html` 即可运行
- 已实现：选择目标（减肥 / 美丽 / 成长 / 自定义）→ 按目标生成每日任务清单 → 点击打勾 → 完成进度条 → 手动添加任务 → “新的一天”重置 → 按日期存在浏览器 localStorage
- 未实现：建档、属性成长（Beauty / Aura / Charm / Money / Power）、成就、连续天数

v1 在 `../src/` 里用 React + Vite 重建，沿用了这里的任务模板、本地存储和进度条思路。
